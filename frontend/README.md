# Frontend (대협 담당)

React.js (웹) / React Native (앱)

## 폴더 구조 (예정)

```
frontend/
├── web/           # React.js 웹 버전
├── app/           # React Native 앱 버전
└── shared/        # 웹·앱 공유 컴포넌트, 타입, 유틸
```

## 시작하기

```bash
# 웹
cd web && npm install && npm start

# 앱
cd app && npm install && npx react-native run-android
```

## 담당 기능

- [ ] 카카오 로그인 연동
- [ ] 거주 지역 등록 화면

- [ ] 지도 페이지 (채택 명소 마커, 세대 필터, 대안 추천)
- [ ] 로컬패스 표시 및 사용 UI
- [ ] 이 주의 발굴 지역 배너 (메인 화면)
