# 로컬픽 (LocalPick)

> 관광 소외 지역을 데이터로 발굴하고, 거주자가 직접 살리는 지역 관광 균등화 플랫폼

2026 관광데이터 활용 공모전(웹·앱 개발 부문) 출품작

## 팀 구성

| 이름 | 역할 |
|---|---|
| 창현 | 대표자 / 백엔드, API 연동, 예측 알고리즘 |
| 대협 | 프론트엔드, UI/UX, 콘텐츠 |

## 프로젝트 구조 (모노레포)

```
localpick/
├── frontend/    # React.js (웹) / React Native (앱) — 대협 담당
├── backend/     # Spring Boot (Java) — 창현 담당
├── docs/        # 기획서, API 명세, 회의록 등
└── README.md
```

## 기술 스택

- **프론트엔드**: React.js (웹) / React Native (앱)
- **백엔드**: Spring Boot (Java)
- **DB**: MySQL
- **지도**: 카카오맵 API
- **거주자 인증 위치 변환**: 카카오 Reverse Geocoding API
- **서버**: AWS EC2
- **외부 API**: 한국관광공사 OpenAPI 6종

## 핵심 기능

1. **지역 소통방** — 거주자 인증 기반 커뮤니티, 채택 시스템
2. **지도 페이지** — 채택 명소 탐색 + 대안 장소 추천
3. **지역 관광 균등화 예측** — 공사 API 3개 조합 알고리즘

## 브랜치 전략

- `main`: 배포 가능한 안정 버전만
- `develop`: 개발 통합 브랜치
- `feature/프론트-기능명`, `feature/백엔드-기능명`: 기능별 작업 브랜치
