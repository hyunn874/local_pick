# LocalPick 에러 코드 레퍼런스

> **최종 갱신:** 2026-08-28

모든 에러 응답은 아래 형식을 따른다.

```json
{
  "success": false,
  "code": "A001",
  "message": "로그인이 필요합니다."
}
```

---

## 공통 (C)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| C001 | 400 | 입력값이 올바르지 않습니다. | @Valid 검증 실패, 필수 파라미터 누락, 형식 불일치 |
| C002 | 500 | 서버 오류가 발생했습니다. | 예상치 못한 서버 내부 에러 |

## 인증 (A)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| A001 | 401 | 로그인이 필요합니다. | Authorization 헤더 누락 또는 인증되지 않은 요청 |
| A002 | 401 | 유효하지 않은 토큰입니다. | JWT 서명 불일치, 잘못된 토큰 형식 |
| A003 | 401 | 토큰이 만료되었습니다. 다시 로그인해 주세요. | Access/Refresh Token 만료 |
| A004 | 401 | 카카오 로그인에 실패했습니다. | 카카오 토큰 교환 실패, 사용자 정보 조회 실패 |
| A005 | 403 | 닉네임과 세대 설정을 완료해 주세요. | 온보딩 미완료 사용자의 인증 필요 API 접근 |
| A006 | 401 | Apple 로그인에 실패했습니다. | Apple identityToken 검증 실패 (서명, 만료, aud 불일치) |
| A007 | 400 | 인증 가능한 기간이 아닙니다. 다음 인증 가능일을 확인해 주세요. | 거주자 인증 윈도우 밖에서 시도 |

## 회원 (U)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| U001 | 404 | 사용자를 찾을 수 없습니다. | 존재하지 않는 userId |
| U002 | 409 | 이미 사용 중인 닉네임입니다. | 닉네임 중복 |
| U003 | 409 | 이미 설정을 완료한 계정입니다. | 온보딩 재시도 |
| U004 | 403 | 탈퇴한 계정입니다. | 소프트 삭제된 계정으로 로그인 시도 |

## 지역 (R)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| R001 | 404 | 지역을 찾을 수 없습니다. | regionCode 또는 시도+시군구에 매칭되는 지역 없음 |

## 게시글·채택 (P)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| P001 | 404 | 게시글을 찾을 수 없습니다. | 존재하지 않는 postId |
| P002 | 409 | 이미 채택에 참여했습니다. | 동일 사용자가 같은 게시글에 중복 채택 |
| P003 | 403 | 해당 지역 거주자 인증이 필요합니다. | 거주자 미인증 사용자의 제한된 기능 접근 |
| P004 | 403 | 본인이 작성한 글만 수정할 수 있습니다. | 타인의 게시글 수정/삭제 시도 |

## 로컬패스 (L)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| L001 | 400 | 로컬패스 잔액이 부족합니다. | 잔액 < 사용 요청 금액 |

## 외부 연동 (E)

| 코드 | HTTP | 메시지 | 발생 상황 |
|------|------|--------|-----------|
| E001 | 502 | 외부 API 호출에 실패했습니다. | 한국관광공사 API, KOSIS, MOIS 등 외부 서비스 장애 |

---

## 프론트엔드 처리 가이드

| 코드 | 권장 처리 |
|------|-----------|
| A001, A002, A003 | 로그인 화면으로 이동 (토큰 삭제 후 재로그인 유도) |
| A005 | 온보딩 화면으로 이동 |
| A007 | nextVerifyDate 표시 + 토스트 메시지 |
| U002 | 닉네임 입력 필드에 인라인 에러 |
| U004 | "탈퇴한 계정입니다" 안내 후 로그인 화면 유지 |
| C001 | 해당 입력 필드에 인라인 에러 |
| C002, E001 | "잠시 후 다시 시도해 주세요" 토스트 |
