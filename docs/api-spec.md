# 한국관광공사 OpenAPI 활용 명세

## 사용 API 6종

| API명 | 구분 | 용도 | 발급 상태 |
|---|---|---|---|
| 관광빅데이터 정보서비스 | 핵심 | 예측 알고리즘 1단계 — 지역별 방문자 수 추이 | ⬜ 신청 전 |
| 지역별 관광 수요 강도 | 핵심 | 예측 알고리즘 2단계 — 체류·소비 강도 지수 | ⬜ 신청 전 |
| 지역별 관광 다양성 지수 | 핵심 | 예측 알고리즘 3단계 + 효과 측정 | ⬜ 신청 전 |
| 관광지별 연관 관광지 | 필수 | 지도 페이지 코스 추천 | ⬜ 신청 전 |
| 국문관광정보 서비스 | 필수 | 명소 등록 자동화 | ⬜ 신청 전 |
| 관광사진 정보 | 보조 | 초기 콘텐츠 공백 보완 | ⬜ 신청 전 |

## 인증키 발급 절차

1. [공공데이터포털](https://data.go.kr) 회원가입
2. 검색창에 '한국관광공사' 검색 → 사용할 API 선택 → '활용신청' 클릭
3. 마이페이지 > 데이터활용 > OpenAPI > 인증키 발급 현황에서 확인

## 알고리즘 가중치 설계

| API | 가중치 | 판단 기준 |
|---|---|---|
| 관광빅데이터 (방문자 추이) | 40% | 방문자 증가율 전월 대비 +10% 이상 |
| 지역별 관광 수요 강도 | 35% | 관광 소비 강도 지수 전국 평균 이하 |
| 지역별 관광 다양성 지수 | 25% | 관광객 다양성 지수 하위 30% 이하 |

세 조건 동시 충족 지역을 매주 자동 선정, 상위 3개 지역을 "이 주의 발굴 지역"으로 노출.
